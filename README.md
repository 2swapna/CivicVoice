# CivicVoice

### Community Problem Reporting Web Application

CivicVoice is a full-stack web application designed to help citizens report local community problems and interact with other community members.

Users can create an account, log in, report civic problems, upload photos, support reported problems, and post comments. An admin can view reported problems and send replies.

## Project Overview

CivicVoice provides a simple digital platform for reporting and discussing problems such as:

- Road and pothole issues
- Garbage and waste problems
- Streetlight problems
- Water-related issues
- Other local community problems

The application connects the citizen-facing interface with a Python Flask backend and SQLite database.

---

## Features

### Citizen Features

- User Registration
- User Login
- Login using username, phone number, or email
- Report community problems
- Select problem category
- Add problem location
- Add problem description
- Upload problem photos
- View community reports
- Support reported problems
- Add comments
- View admin replies
- View problem status

### Admin Features

- Admin Login
- View reported problems
- View reported problem details
- View uploaded problem images
- View support count
- View problem status
- Send replies to citizens
